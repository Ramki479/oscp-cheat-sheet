When this page and the official guide disagree, the official guide wins — and you are responsible for knowing it. ## Exam shape | Item | Value | | --- | --- | | Exam time | 23 hours 45 minutes | | Report upload window | 24 hours after the exam ends | | Machines | 3 standalone + 1 AD set of 3 machines | | Points | standalone 20 each (10 initial + 10 privesc) = 60 · AD set 10 + 10 + 20 = 40 | | Maximum raw points | 100 | | Proctoring | All exams proctored | | Connection | Kali Linux over OpenVPN, using the supplied .ovpn file | AD set: you are given a username and password, simulating a breach. You are not expected to break in from nothing. Point allocation: machines are graded in the order you document them; each has specific objectives listed in the exam control panel. Pass mark: this version of the guide states the 100-point maximum and that scaled scoring applies to exams starting on or after 1 December 2026, 08:00 GMT (see the OSCP+ Scaled Scoring FAQ). It does not restate a raw pass threshold — confirm the current pass rule in the guide/FAQ before your exam rather than relying on the old 70/100 figure. ## Proof rules — where most points are lost - Each target has at least one proof file: local.txt (unprivileged) and proof.txt (root/Administrator). - You must submit the file contents in the control panel before the exam ends. - You must also show the contents in a screenshot, together with the target IP from ipconfig, ifconfig or ip addr. - Read the file from its original location, using cat or type, in an interactive shell. - A web shell, or any other retrieval method, scores zero for that machine. - Windows full points require a shell as SYSTEM, Administrator, or a user with Administrator privileges. Linux full points require root. ## Report rules - A professional report covering every attack: all steps, commands issued, and console output — detailed enough for a competent reader to replicate it. - Once submitted, the submission is final. Missing screenshots cannot be added later. - Unmodified exploit: give the URL only; do not paste pages of third-party code. - Modified exploit: include the modified code, the original URL, the shellcode-generation command (if any), highlighted changes, and why you changed them. - Suggested templates: the official Word or OpenOffice report template (or your own, if structured and professional). ## Tool restrictions ### Not permitted - Spoofing — IP, ARP, DNS, NBNS, etc. - Commercial tools or services — Metasploit Pro, Burp Pro, etc. - Automatic exploitation tools — db\_autopwn, browser\_autopwn, SQLmap, SQLninja, etc. - Mass vulnerability scanners — Nessus, NeXpose, OpenVAS, Canvas, Core Impact, SAINT, etc. - AI chatbots — OffSec KAI, ChatGPT, YouChat, DeepSeek, Gemini, etc. Using LLMs is treated as receiving third-party help. - Features inside otherwise-allowed tools that perform any of the above. ### Permitted (examples named in the guide) - Nmap (including its scripting engine), Nikto, Burp Free, DirBuster, and similar manual tools. - Tools with built-in AI features (e.g. Notion, Google AI Overview) do not need to be disabled — but you may not use the AI features to solve exam tasks. - Discord may be used to search for information, but never to request or receive help. > You are responsible for knowing what a tool does under the hood. "A tool did it automatically" is not a defence. ## Metasploit restrictions - Metasploit modules (Auxiliary, Exploit, Post) or Meterpreter may be used against one target machine only — your choice, locked in from the first use. - You may not use check (or modules) against several machines to pick a target. Testing multiple machines with Metasploit selects your one machine by that act. - If the attempt on your chosen machine fails, you may not move Metasploit to a second machine. - Metasploit cannot be used for pivoting (that would touch more than one target). - multi/handler and msfvenom may be used against all machines — but a Meterpreter payload still counts as Meterpreter and is limited to one machine. - The same limits apply to Armitage, Cobalt Strike, Metasploit Community Edition, and similar interfaces. ## Reverts - 24 reverts, and the limit can be reset once during the exam. - All machines start freshly reverted. - Click once per attempt and wait — a revert discards all your changes on that machine. ## Scoring disqualifiers No points for a machine if you: - used a restricted tool; - used Metasploit Auxiliary/Exploit/Post or Meterpreter on more than one machine; - failed to provide local.txt/proof.txt in both the control panel and an interactive-shell screenshot; - did not document the work. ## Submission mechanics | Step | Requirement | | --- | --- | | Format | PDF only, all scripts/PoCs as text inside the PDF | | File name | OSCP-OS-XXXXX-Exam-Report.pdf (case-sensitive; OS-XXXXX is your OSID) | | Archive | .7z, no password, same base name | | Size | ≤ 200 MB | | Upload | [https://upload.offsec.com](https://upload.offsec.com) within 24 hours of exam end | | Verify | compare the MD5 shown after upload with md5sum of your local file | | Results | email within 10 business days | ```bash sudo 7z a OSCP-OS-XXXXX-Exam-Report.7z OSCP-OS-XXXXX-Exam-Report.pdf md5sum OSCP-OS-XXXXX-Exam-Report.7z ``` ## Before your exam — re-confirm these - ☐ Current exam guide version and its date - ☐ Pass rule (raw vs scaled scoring) and effective date - ☐ Tool restriction list, including the AI policy - ☐ Metasploit limits and whether msfvenom/handler wording changed - ☐ Report template and file-naming rules - ☐ Upload URL and size limit > Anything you cannot confirm from the official guide on the day should be treated as "confirm with current official guide" — not assumed. ## Related pages - [OSCP Attack Workflow — Start Here](https://app.notion.com/p/4011e51238b581c5ad53c7704de0ebc5) - [OSCP Exam Checklist & Evidence Collection](https://app.notion.com/p/4011e51238b58192a726f4738738085a) - [OSCP Machine Notes — Template](https://app.notion.com/p/4011e51238b5811cb117f8335df3a46f) - 📖 OSCP Command Handbook ## Reference - OSCP+ Exam Guide: [https://help.offsec.com/hc/en-us/articles/360040165632-OSCP-Exam-Guide](https://help.offsec.com/hc/en-us/articles/360040165632-OSCP-Exam-Guide) - AI Usage Policy in OffSec Exams: [https://help.offsec.com/hc/en-us/articles/35549468971156](https://help.offsec.com/hc/en-us/articles/35549468971156) - OSCP+ Exam FAQ: [https://help.offsec.com/hc/en-us/articles/4412170923924](https://help.offsec.com/hc/en-us/articles/4412170923924) - Scaled Scoring FAQ: [https://help.offsec.com/hc/en-us/articles/54589877508884](https://help.offsec.com/hc/en-us/articles/54589877508884) ## Verification note All exam-specific statements above were read from the official OSCP+ Exam Guide on 22 October 2026 (guide updated 21 October 2026).
